🔗 GitHub 연결

제목·관심 주제·바로가기를 바꾸면 GitHub의 config.json 파일에 저장되고, 뉴스 수집 프로그램이 그 파일을 읽어요. 이 저장을 하려면 토큰(임시 열쇠)이 한 번 필요해요.
토큰 만드는 방법 (처음 한 번만)
  1. github.com에 로그인한 뒤 오른쪽 위 프로필 사진 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name은 아무거나(예: dashboard), Expiration은 원하는 기간
  4. Repository access에서 Only select repositories를 고르고 my-dashboard 선택
  5. Permissions → Repository permissions → Contents를 Read and write로
  6. 맨 아래 Generate token → 나온 github_pat_… 글자를 복사해 아래에 붙여넣기 (한 번만 보여요)
